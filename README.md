# 👥 Presence Counter (Детектор присутності з лічильником та EEPROM)

Автономний лічильник відвідувачів / спрацьовувань на базі мікроконтролера **Arduino Mega 2560**, інфрачервоного датчика руху **HC-SR501** та дисплея **LCD 1602 (I2C)**. 

Система фіксує появу нових об'єктів у зоні дії, веде обліковий підрахунок, відображає поточне значення на екрані та автоматично зберігає дані в енергонезалежну пам'ять **EEPROM**, щоб лічильник не скидався при вимкненні живлення.

---

## 🛠️ Компоненти та обладнання

* **Мікроконтролер:** Arduino Mega 2560 (або Uno / Nano)
* **Датчик руху/присутності:** HC-SR501 PIR Sensor
* **Дисплей:** LCD 1602 з модулем I2C (адреса `0x27`)
* **Пам'ять:** Енергонезалежна EEPROM (вбудована в мікроконтролер)
* **Живлення:** USB 5V або зовнішній блок живлення 7–12V

---

## 🔌 Схема підключення (Pinout)

| Компонент | Пін компонента | Пін Arduino Mega 2560 |
| :--- | :--- | :--- |
| **HC-SR501 (PIR)** | OUT (Сигнал) | `Digital Pin 9` |
| **HC-SR501 (PIR)** | VCC / GND | `5V` / `GND` |
| **LCD 1602 I2C** | SDA / SCL | `SDA (Pin 20)` / `SCL (Pin 21)` |
| **LCD 1602 I2C** | VCC / GND | `5V` / `GND` |

## 💡 Логіка роботи та особливості

1. **Відновлення даних при старті (`setup()`):**
   * При подачі живлення програма зчитує збережене значення `presenceCount` із пам'яті EEPROM за адресою `0`.
   * Перевіряється цілісність даних (захист від першого запуску та залишків «сміття»).
   * Відновлене число одразу виводиться на другий рядок екрана LCD.

2. **Алгоритм виявлення фронту (Edge Detection):**
   * Програма фіксує лише момент **переходу сигналу з `LOW` у `HIGH`** (поява людини).
   * Тривала присутність об'єкта перед датчиком не призводить до повторного безперервного нарощування лічильника.

3. **Захист від повторних спрацьовувань (Debounce):**
   * Впроваджено часовий фільтр `DEBOUNCE_TIME = 1000 мс`.
   * Повторні короткі імпульси чи шуми, що виникають частіше ніж 1 раз на секунду, автоматично ігноруються.

4. **Безпечний запис у EEPROM (`EEPROM.put()`):**
   * Використовується функція `put()`, яка перезаписує байт у пам'яті лише у випадку змінення значення. Це береже ресурс комірок пам'яті мікроконтролера.

## 🚀 Як запустити проект

1. Відкрийте проект у **PlatformIO** (VS Code) або **Arduino IDE**.
2. Встановіть бібліотеки:
   * `LiquidCrystal_I2C`
   * `EEPROM` *(вбудована у стандратне ядро Arduino)*
3. Перевірте викручені потенціометри на HC-SR501:
   * **Sensitivity (Чутливість):** налаштуйте дистанцію виявлення.
   * **Time Delay (Затримка):** викрутіть проти годинникової стрілки на мінімум.
4. Завантажте C++ прошивку в **Arduino Mega 2560**.

---

## ⚙️ Основні константи в коді

* `sensorPin = 9` — цифровий пін підключення виходу `OUT` PIR-датчика.
* `EEPROM_ADDR = 0` — початкова адреса в пам'яті EEPROM для збереження змінної `presenceCount`.
* `DEBOUNCE_TIME = 1000` — затримка між зарахуванням нових подій у мілісекундах.
